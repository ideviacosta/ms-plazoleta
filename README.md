Este repositorio contiene un microservicio backend desarrollado en Java y Spring Boot, diseñado para gestionar una plazoleta de comidas. El servicio expone APIs REST para la administración de restaurantes, platos y pedidos, aplicando arquitectura hexagonal (Ports & Adapters), principios de Clean Architecture y DDD táctico.

Incluye manejo de seguridad mediante JWT, validación de roles, separación clara de responsabilidades, pruebas unitarias a nivel de dominio y una estructura pensada para ser escalable, mantenible y preparada para entornos cloud.
